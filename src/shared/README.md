# Shared

Elementos reutilizables que no pertenecen a un motor ni a una plataforma:
componentes visuales genéricos, estilos, tipos de presentación, utilidades y
constantes transversales.

- No importa desde `features`.
- No contiene reglas de negocio ni detalles de navegador.
- Debe tener una finalidad claramente transversal antes de añadirse aquí.
