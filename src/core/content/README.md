# Contratos de contenido

Este directorio define el vocabulario estable de currículo y actividades antes
de elegir si los manifiestos se almacenan como JSON o TypeScript.

- Los IDs técnicos se escriben en inglés: por ejemplo, `mathematics`,
  `primary-1` y `counting`.
- Los títulos y descripciones destinados al profesorado se escriben en español.
- `ActivityManifest` describe contenido; no incluye imports de React ni acceso
  a navegador, red o IndexedDB.
- `ActivityResult` no contiene nombres ni identificadores de alumnado en V1.
