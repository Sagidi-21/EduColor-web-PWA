# EduColor web PWA

Nueva plataforma web progresiva de EduColor. El proyecto Electron original se mantiene intacto como referencia funcional y fuente de migración selectiva.

## Arranque

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run typecheck
npm test
npm run build
```

Consulta [la arquitectura inicial](docs/ARQUITECTURA_INICIAL.md), el [roadmap operativo auditado](docs/ROADMAP_AUDITADO.md) y el [plan de ejecución detallado](docs/ROADMAP_DE_EJECUCION_DETALLADO.md).
