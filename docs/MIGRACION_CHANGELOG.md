# Migration Changelog

Registro de decisiones donde la PWA diverge intencionalmente del proyecto original (Electron).

| Componente Original                                  | Cambio                                                                                                                                                                                                                                                                                 | Motivo                                                                                                                                                                                                                                        | Impacto                                                                                                                                                                                                   | Responsable                             | Fecha      |
| :--------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------- | :--------- |
| `window.api.playCorrect`                             | Sustituido por Web Audio API pura                                                                                                                                                                                                                                                      | PWA no tiene acceso a IPC ni archivos del sistema                                                                                                                                                                                             | Generación de audio 100% en navegador                                                                                                                                                                     | Agente                                  | 2026-09-11 |
| Vídeo de intro (autoplay)                            | Iniciado en 'muted', se reproduce audio al primer gesto                                                                                                                                                                                                                                | Políticas restrictivas de autoplay en navegadores                                                                                                                                                                                             | Mismo flujo visual, previene bloqueo                                                                                                                                                                      | Agente                                  | 2026-09-11 |
| `window.api.saveSamplesToDisk(json)`                 | Eliminado en PWA; el backup se ofrecerá como botón "Descargar backup" en Configuración (implementación pendiente)                                                                                                                                                                      | `window.api` es IPC exclusivo de Electron; no existe en navegador                                                                                                                                                                             | El fine-tuning automático y el almacén IndexedDB funcionan sin cambios; solo se pierde el backup automático a disco del servidor/PC. Las muestras persisten en el navegador del dispositivo del profesor. | Agente + usuario                        | 2026-09-11 |
| `DrawableAnswerBox` — handlers mouse/touch separados | Sustituido por **Pointer Events** unificados (`onPointerDown`, `onPointerMove`, `onPointerUp`)                                                                                                                                                                                         | Las pizarras digitales envían eventos de pointer, no mouse/touch; Pointer Events es el estándar web moderno para entrada táctil y de lápiz                                                                                                    | Mejor compatibilidad con pizarras digitales reales; el comportamiento visual es idéntico                                                                                                                  | Agente + roadmap Fase 5                 | 2026-09-11 |
| `relacionar/RelacionarRenderer` (Electron) → PWA     | Motor extraído a `src/core/activities/relacionar.ts` (sin `engine.ts` en Electron); renderer portado a `src/features/matematicas/relacionar/RelacionarScreen.tsx` usando `ActivityHeader`, `SummaryScreen` y `ActivityActionButtons` compartidos                                       | El original mezclaba lógica y UI en el propio renderer; la PWA separa núcleo puro (sin React) y renderer táctil                                                                                                                               | Paridad visual y de flujo; 15 tests de generador determinista; build verde                                                                                                                                | Agente                                  | 2026-09-15 |
| `Numpad` duplicado en `Numeracion1119Screen.tsx`     | Eliminado el `Numpad` interno (30 líneas, layout own `ops__numpad`); la pantalla ahora usa el componente compartido `src/features/shared/components/Numpad.tsx` (`shared-numpad`). Corregido bug de tecla de confirmación: las dos teclas `?` invocaban `onDelete`, nunca `onConfirm`. | DT-004 — unificar teclado numérico y modos de entrada. El duplicado rompía la estética del resto de motores y la tecla de confirmación era inalcanzable.                                                                                      | Mismo comportamiento de entrada; CI verde (lint 0, typecheck 0, 320/320 tests).                                                                                                                           | Agente                                  | 2026-09-16 |
| Orden de fases — Fase 5 adelantada                   | La Fase 5 (escritura de dígitos y ML) se ejecuta antes de completar todas las actividades P1 de la Fase 2                                                                                                                                                                              | Varias actividades P1 (`numeracion1119`, `suma`, `resta`, `igualdad`, `algoritmoVertical`, etc.) dependen del canvas para las dificultades medium/hard/expert. Completarlas a medias sería más costoso que desbloquear el subsistema primero. | Desbloquea 6+ actividades de golpe; no altera el orden del roadmap maestro, solo la secuencia de ejecución dentro del sprint                                                                              | Usuario — decisión explícita 2026-09-11 |
